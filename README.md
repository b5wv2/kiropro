# KIROPRO - منصة شحن الألعاب والمنتجات الرقمية

مشروع KIROPRO مقسم إلى جزأين رئيسيين يعملان بشكل مستقل (Frontend و Backend) لضمان بنية قوية وقابلة للتطوير.

## هيكلة المشروع (Project Structure)

```text
kiropro/
├── server/                 # ← الـ Backend (Node.js + Express + SQLite)
│   ├── src/                # الكود المصدري للـ API
│   ├── package.json        
│   └── README.md           # تعليمات تشغيل الـ Backend
│
├── src/                    # ← الـ Frontend (React + TypeScript + Vite)
│   ├── components/         # واجهات المستخدم
│   ├── context/            # إدارة الحالة (Auth, Wallet, etc)
│   ├── pages/              # صفحات الموقع ولوحة تحكم الإدارة
│   └── ...
│
├── index.html              # المدخل الرئيسي للـ Frontend
├── package.json            # تبعيات الـ Frontend
└── vite.config.ts          # إعدادات Vite
```

## 🚀 كيفية تشغيل المشروع

لتشغيل المشروع بشكل كامل في بيئة التطوير، يجب تشغيل **كلا الخادِمَين (Backend و Frontend)** في نافذتي Terminal منفصلتين.

### 1️⃣ تشغيل الـ Backend (الخطوة الأولى)

الـ Backend هو السيرفر الذي يدير قاعدة البيانات، حسابات المستخدمين، وعمليات الدفع والشحن. يجب أن يعمل أولاً حتى يستطيع الـ Frontend الاتصال به.

افتح **Terminal 1** ونفذ الأوامر التالية:

```bash
cd server
npm install
npm run dev
```

> **ملاحظة هامة**: السيرفر سيعمل على المنفذ `5000` (أي `http://localhost:5000`). لا تقم بإغلاق هذا التيرمنال، دعه يعمل في الخلفية. ستجد تعليمات مفصلة أكثر حول قاعدة البيانات في `server/README.md`.

### 2️⃣ تشغيل الـ Frontend (الخطوة الثانية)

واجهة المستخدم مبنية باستخدام Vite و React. 

افتح **Terminal 2** (تيرمنال جديد) ونفذ الأوامر التالية في المجلد الرئيسي للمشروع (`kiropro`):

```bash
npm install
npm run dev
```

> **النتيجة**: سيعمل الموقع على `http://localhost:5173`. افتح هذا الرابط في المتصفح، وسيقوم الموقع بالاتصال تلقائياً بالـ Backend.

## 🔐 نظام الإدارة (Admin Dashboard)

المشروع يحتوي على لوحة تحكم كاملة للمديرين (Admin Dashboard) متصلة فعلياً بالـ Backend وتدير الطلبات والرصيد بشكل حي (Real-time).

### الدخول للوحة التحكم
يتم إنشاء حساب مدير افتراضي تلقائياً في قاعدة البيانات عند تشغيل الـ Backend لأول مرة.

- **البريد الإلكتروني**: `admin@kiropro.com`
- **كلمة المرور**: `admin123`

بمجرد تسجيل الدخول بهذا الحساب في واجهة المتجر `http://localhost:5173`، سيقوم النظام باكتشاف صلاحياتك (`role=ADMIN`) من الـ Backend، وسيقوم بتحويلك **مباشرةً** إلى لوحة تحكم الإدارة (بدلاً من المتجر العادي).

### حماية المسارات (Security)
- الـ Frontend يمنع أي مستخدم عادي (`CUSTOMER`) من فتح لوحة التحكم، ويعيده للمتجر.
- الـ Backend يحمي مسارات الـ API الخاصة بالإدارة (`/api/admin/*`)، ولا يمكن لأي مستخدم عادي استدعاؤها حتى لو حاول تجاوز الواجهة.
